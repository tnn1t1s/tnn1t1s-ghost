# tests/

Test suites for the repo.

- `unit/` — Python (pytest) unit tests for the panelkit toolkit
- `integration/` — Python tests of engine/module behavior
- `stress/` — headless C++ DSP stress harness (`make stress`)
- `patches/` — hand-built `.vcv` regression/calibration patches you audition in
  Rack (not auto-graded)
